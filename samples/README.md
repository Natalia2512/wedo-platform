# Sample files

Small files (< 5 MB each) that let everyone run and test the code without downloading real datasets.

| File | What | Source |
|---|---|---|
| `WeDO_SYNTHETIC_Torino_2011-2020.epw` | Valid EPW format, synthetic weather. For testing the runner and EPW readers only, never for design | generated by `api/provider.py` |

Only add files that are synthetic or whose licence allows redistribution (with attribution). Never add CMCC data.
